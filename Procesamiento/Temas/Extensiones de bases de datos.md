# Extensiones de bases de datos

## Extensión .dat
Aquí están las **señales crudas del ECG**  
Es un archivo binario.  
Contiene los valores digitales de los canales (canal 0 y canal 1).

No es texto. No lo puedes abrir con bloc de notas.

## Extensión .hea
Es el archivo de **cabecera (header)**  

Contiene:
- Número de canales
- Frecuencia de muestreo
- Ganancia
- Formato
- Qué [[Derivaciones cardiacas|Derivación]] está en cada canal

Este archivo sí es texto.

## Extensión .atr
Archivo de **anotaciones**  
Contiene:

- Latidos marcados
- Arritmias
- Eventos clínicos

Se usa para clasificación, no para saber las derivaciones.

## Extensión .xws 
Es un archivo de configuración para el visor Wave (WFDB)  
No lo necesitas para tu pregunta.
