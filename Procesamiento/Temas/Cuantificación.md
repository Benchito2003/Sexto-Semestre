# Cuantificación
- Proceso de convertir una señal discreta en el tiempo con amplitud continua en una señal digital expresando cada valor de muestra como un numero finito de dígitos 𝑥𝑞 𝑛 = 𝑄 𝑥[𝑛] 
- Error de cuantificación o ruido de cuantificación: error inherente al representar la señal continua mediante un conjunto finito de niveles discretos 𝑒𝑞 𝑛 = 𝑥𝑞 𝑛 − 𝑥[𝑛]
- Al conjunto de todos los niveles de cuantificación se le llama rango de cuantifiación.
- A la diferencia entre niveles de cuantificación se les llama *Escalón de cuantificación*
- En el redondeo el error de cuantificación no puede ser mayor a medio escalón de cuantifiación.
- Si tenemos una frecuencia adecuada de muestreo, solo tendremos el error de cuantifiación, siempre tendremos un error de cuantificación debido a las limitaciones de hardware.

Es pasar de amplitud continua a amplitud discreta.
