# Clasificación de señales
- Según la fuente (o naturaleza física):
- De acuerdo a las características:

### Señales continuas y discretas
- Señales continuas: se describen mediante una función de tiempo y amplitud continuos $s(t)$
- Señales discretas: se describen mediante una secuencia $S[n]$ de tiempo y amplitud discreta
La mayoría de las señals biomédicas son contínuas


### Señales deterministas y estocásticas
#### Señales Deterministas
Deterministas: se pueden describir mediante una gráfica o una función matemática.
Son predecibles y reproducibles a partir de su descripción matemática.
Ejemplos: señales  sinusoidales y señales no periódicas con una forma de onda específica.
Las señales 

- Se dividen en periódicas y no periódicas
- Señales periódicas: compuestas de una s

#### Señales Estocásticas
Se modelan como muestras de un proceso
