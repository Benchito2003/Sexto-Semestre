# Variables de control
Es importante determinar la variable de control, pues los microcontroladores no pueden derivar, por lo que complica las cosas con movimientos uniformemente acelerado que dependen de la derivada.
Solo podemos meter variables algebraicas en un microcontrolador.
Podemos usar métodos matemáticos para simplificar métodos numericos para simplificar ecuaciones diferenciales.
