# ¿Qué es control?
El está implícito en varias partes de nuestra vida, pues permite que la sociedad funcione.
==El control es modificar el comportamiento de una variable para que se comporte dentro de **dos *parámetros***.==

Al valor al que queremos que trabaje el sistema, se le llama **Set Point**

Aunque pongamos un *Set Point* (valor que queremos que tenga la variable), realmente no vamos a llegar a un valor fijo, por lo que tenemos que jugar con estos parámetros; que tan lejos o que tan cerca estemos del Set Point se le conoce como **Error**, y podemos ajustar el sistema para poder tener un error bajo.

Los sistemas que oscilan llevan una **Inercia**, en analogía: *Aunque apaguemos la flama del horno, este seguirá calentando un poco más antes de enfriarse*.
