# Funciones milis y micros
*milis(), micros()*
Regresa los milisegundos o microsegundos transcurridos desde que se arrancó el programa (reset)
Estas son muy útiles si buscamos hacer dos tareas al mismo tiempo,  pues no siempre podemos usar la función "delay()"
